# 東京ヴェルディ販売日程 iframe 対応パッチ v0.1

## 症状
2026/10/17 東京ヴェルディ vs FC東京について、
東京ヴェルディ公式では販売日が発表済みなのに、
クラブチケットナビでは「未発表」と表示される。

## 原因
東京ヴェルディの販売スケジュール表は、
`https://www.verdy.co.jp/content/ticket/buy/`
の本文ではなく iframe 内の販売表にあります。

従来のスクレイパーは親ページだけを確認していたため、
FC東京戦の販売日を取得できませんでした。

また、表には `9/18` のように日付のみが入り、
開始時刻 `12:00` は親ページの共通注記に記載されています。

## 修正
- 同一ドメインの iframe を最大5件まで追跡
- iframe の試合行から一般販売日を取得
- 親ページの共通販売開始時刻を補完して日時化
- 東京V以外でも同じ形式のクラブに使える汎用実装

現在の東京V戦は、次の値として取得されます。

`2026-09-18T12:00:00+09:00`
