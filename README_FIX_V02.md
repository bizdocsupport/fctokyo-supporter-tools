# FC東京日程パーサー修正版 v0.2

## 今回の #121 のエラー

失敗:
`test_schedule_or_date_split_lines`

期待値:
`2027/05/22(土) or 2027/05/23(日) 時刻未定`

前版の結果:
`2027/05/23(日) 時刻未定`

## 原因

候補日が、

```text
5月22日(土) or
5月23日(日)
```

のように2行へ分割されるケースで、
2行目を「次の試合の日付」と誤判定していました。

## 修正

- `or` に続く2つ目の日付は同一試合の候補日として扱う
- FC東京公式の現行レイアウト対応を維持
- 終了済み試合のスコア形式対応を維持
- 東京V iframe対応を維持
- 鹿島SSL対応を維持

## テスト

旧版の全テストに加え、以下の回帰テストを実行済みです。

- 候補日が2行に分かれるケース
- 現行FC東京公式レイアウト
- 終了済み試合と次試合の混在防止

`TEST_RESULTS.txt` に実行結果を同梱しています。
